# AsRecorded

AsRecorded reads the history of GitHub repositories and writes a record of how each change reached the default branch in a period: who or what built it, who or what let it in, whether a person gave an approval, and which checks ran on the merged version.

It only reads. It installs nothing in the repositories it reads and changes nothing in them, and it needs nothing else installed. It never calls an AI model when it runs: the same saved data gives the same record.

This is a first stub. The tool is not built yet.
